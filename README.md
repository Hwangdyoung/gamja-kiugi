# 감자 키우기

디자인씽킹 조별 과제 모바일 앱입니다. 춘천에 있는 대학생이 학교 다니는 동안 **전공 경험을 쌓도록** 학년별 할 일과 춘천·온라인 기회를 보여 줍니다.
캐릭터 감자는 앱을 안 열면 화를 내고, 진로 행동(기회 보기·스크랩·기록)을 하면 물·햇빛·거름을 받아 자랍니다.

- 웹: https://gamja-kiugi.vercel.app (발표용)
- iPhone 앱 + 홈 화면 위젯 + Apple Watch 앱: 같은 코드를 Capacitor로 감쌌습니다 → [docs/ios-widget.md](docs/ios-widget.md)
- 기획안: Claude 문서 "감자 키우기 서비스 기획안 v2"

## 핵심 규칙

- **표정**: 마지막 접속 후 0~1일 웃음 → 2~3일 무표정 → 4~6일 짜증 → 7일~ 분노. 위젯·워치·알림도 같은 규칙.
- **알림**: 하루 한 번까지, 정한 시각(기본 오전 10시)에만. 미접속 알림은 표정이 바뀌는 날(2·4·7일째)과 그 뒤 주 1회. 스크랩한 기회는 마감 3일 전·하루 전, 정기 모집은 열리는 달 1일. 같은 날이면 마감 > 모집 열림 > 미접속.
- **로드맵**: 학년마다 할 일 3개, 12개를 다 기록해도 "취업 성공"이 아니라 "이 기록으로 지원서 써 보자"로 끝납니다.
- **감자 돌보기**: 물(하루 한 번 앱 열기), 햇빛(기회 원문을 처음 열거나 처음 스크랩), 거름(할 일에 처음 기록). 주면 기운이 오르고 하루에 12씩 빠집니다. 레벨·점수·미니게임은 없습니다.
- **성장**: 기록 3개마다 감자 머리 위 싹이 한 칸(씨감자 → 새싹 → 잎 → 꽃봉오리 → 꽃).

## 저장

- 기기(localStorage `oo-kiugi:v2`): 프로필, 기록, 스크랩, 알림·화면 설정, 돌보기.
- 로그인하면 프로필·기록·스크랩·알림 켜기가 계정(Supabase `progress` 표)에도 저장돼 다른 폰에서 이어집니다. 기록은 표의 `done` 칸에 그대로 들어갑니다. 설정 방법: [docs/supabase-setup.md](docs/supabase-setup.md)
- 테스트 지표 이벤트는 기기에 쌓이고(설정 → 시연·테스트 도구 → 지표 복사), 로그인하면 `events` 표에도 남습니다. 기록 내용·이름은 남기지 않습니다.

## 시연 도구 (폰 화면 밖, 발표용)

- 미접속 일수 슬라이더(0~14일) → 표정과 그날 알림 미리보기
- 감자 시간: 지금 시각 / 낮 / 밤 (밤 11시~아침 7시엔 감자가 자서, 저녁 발표에서는 "낮"을 고르세요)
- 앱 다시 열기(시작 화면부터), 처음부터 다시(저장 내용 삭제)
- iPhone 앱에서는 설정 → 시연·테스트 도구에서 같은 슬라이더와 "알림 미리 보내기"를 씁니다.

## 기회 목록 고치기 (앱 재설치 없이)

기회 목록은 코드와 분리된 파일 [`src/data/opportunities.json`](src/data/opportunities.json) 하나입니다.
GitHub 웹에서 연필(편집)로 고치고 커밋하면 Vercel이 다시 배포되고, 웹과 iPhone 앱 모두 **다음에 열 때** 새 목록을 받습니다.

- 기회 하나: `id`(영문 소문자·하이픈, 바꾸지 않기), `title`, `type`(서포터즈·공모전·프로젝트·인턴·현장실습·취업 중 하나), `org`,
  `due`(모집 중이면 `"2026-12-01"` 모양, 아니면 `null`), `target`, `src`(원문 주소), `when`(정기 모집 시기 글, 없으면 `null`)
- 있으면 쓰는 칸: `where: "온라인"`(온라인 표시), `school: "강원대학교"`(그 학교 재학생에게만 보임), `months: [6]`(매년 모집이 열리는 달 → "곧 열려요"와 알림)
- 로드맵에 넣기: `paths`의 `"dmc.mkt"` 같은 직무 칸에 학년별(1~4학년) 기회 `id` 목록이 있습니다. 각 학년의 "내 직무" 할 일에 붙습니다.
- 조사한 날짜를 바꾸면 `researchedAt`도 고쳐 주세요(상세 화면·설정에 나옴).
- 모양이 틀린 파일(유형 오타, 없는 id 등)을 올리면 앱은 그 파일을 무시하고 이전 목록을 계속 씁니다.

## 실행

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run dev      # http://localhost:5173
npm run test     # vitest
npm run build    # dist/ 에 배포용 파일 생성
npm run preview  # 빌드 결과를 배포와 같은 방식으로 미리 보기
```

로그인을 켜려면 프로젝트 폴더에 `.env.local`(깃에 안 올라감)을 만들고 Supabase 주소와 공개 키를 넣습니다. 자세한 건 [docs/supabase-setup.md](docs/supabase-setup.md).

## 배포 (GitHub → Vercel)

`main`에 push하면 Vercel이 자동으로 다시 배포합니다. 설정은 `vercel.json`에 있어서 Vercel 화면에서 바꿀 값은 환경 변수(`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)뿐입니다.

## iPhone·Apple Watch 설치

무료 Apple 계정으로 설치한 앱은 7일 뒤 실행이 안 됩니다. 발표 1~2일 전에 케이블로 다시 설치하세요. 방법은 [docs/ios-widget.md](docs/ios-widget.md).
