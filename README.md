# 감자 키우기

디자인씽킹 조별 과제 모바일 앱 프로토타입입니다. 기획안(`○○ 키우기 서비스 기획안.md`, 이후 서비스명을 "감자 키우기"로 변경)의 P0 기능을 9:16 폰 화면으로 구현했습니다.

이름과 전공을 입력하면 춘천에서 갈 수 있는 4단계 커리어 경로와 기회를 보여줍니다. 입력한 이름은 감자 캐릭터가 사용자를 부를 때 씁니다.

- 기회 이름, 기관, 마감일, 선배 사례는 모두 **프로토타입용 예시 데이터**입니다. 기관은 실제 기관이 아닌 유형으로만 적었습니다.
- 원문 링크는 실제 공고를 모으기 전이라 "예시 데이터라 원문이 없어요" 안내만 띄웁니다.

## 화면 (하단 탭 4개)

| 화면 | 내용 |
| --- | --- |
| 시작 설정 | 이름·전공·관심 직무 3가지만 입력. 입력 중인 이름을 감자가 바로 불러 줌 |
| 홈 | 검색창, 캐릭터와 말풍선, 진행 상황, 다음 단계, 다음 단계 추천 기회 |
| 기회 | 빠른 필터(P1), 유형 칩 6개 + 스크랩, 검색, 마감 임박 순 정렬, 마감 지난 기회 자동 숨김 |
| 기회 상세 | 주최 기관, 마감일, 대상, 내 경로의 몇 단계인지, 스크랩, 원문 보기 |
| 내 경로 | 1~4단계, 단계별 기회(누르면 상세), 완료로 표시 |
| 선배 | 같은 전공 선배의 경로(내 직무 먼저). 바이오메디컬은 인터뷰 진행 중 안내 |
| 설정(톱니) | 이름·전공·직무 수정(바꾸면 진행 초기화 경고), 푸시 알림 켜기/끄기 |

진행 상황, 스크랩, 알림 설정은 로그인 없이 이 기기(localStorage)에 저장됩니다.

## 시연 도구 (폰 화면 밖)

실제 앱에서는 마지막 접속일로 자동 계산되는 값을 발표에서 보여주기 위한 도구입니다.

- 미접속 일수 슬라이더(0~14일) → 캐릭터 표정: 웃음(0~1) → 무표정(2~3) → 짜증(4~6) → 분노(7~)
- 기획안 7장 알림 규칙에 따라 그날 알림을 보내는지와 이유, 잠금 화면 알림 미리보기
  - 표정이 바뀌는 날(2·4·7일째)에만, 분노 이후엔 주 1회(14·21일째), 오전 10시 발송, 알림을 끄면 안 보냄
- 앱 다시 열기(표정이 웃음으로 돌아옴), 처음부터 다시(저장 내용 삭제)

## 디자인

- 9:16 폰 화면. 실제 폰 폭(520px 이하)에서는 화면 전체를 씁니다.
- 색과 글꼴은 이탈방지턱 앱과 같은 체계입니다: Pretendard, 짙은 파랑 primary, 청록 보조, 슬레이트 회색(oklch).
- 모서리 4~8px, 또렷한 1px 선, 그라데이션·알약 모양 없음. 노랑은 캐릭터 몸에만 씁니다.
- Pretendard는 npm 패키지로 빌드에 함께 묶어 외부 CDN 없이 열립니다.
- 캐릭터·말풍선은 반말 B급 톤, 기회 정보는 존댓말·건조한 정보 톤.
- 레벨·경험치 같은 게임 요소는 넣지 않았습니다(기획안 5장 제외 기능).
- 시스템이 다크 모드여도 항상 밝은 화면으로 엽니다.
- 캐릭터는 감자 일러스트(`src/assets/mascot/*.webp`, 표정 4종). 웃음·짜증·분노는 원본 그림에서 잘랐고, 무표정은 웃음 그림의 입을 일자로 바꿔 만들었습니다.

## 앱 아이콘

- `public/icons/`: 홈 화면 아이콘(192·512px, 안드로이드 maskable, iOS apple-touch-icon), 표정별 탭 아이콘 4개.
- `public/manifest.webmanifest`: 휴대폰에서 "홈 화면에 추가"하면 감자 아이콘과 "감자 키우기" 이름으로 설치됩니다.
- 브라우저 탭 아이콘은 캐릭터 표정을 따라 바뀝니다(기획안 7장의 "앱 아이콘 표정 변화"를 웹에서 시연).
  홈 화면에 설치한 아이콘은 OS 제약으로 자동으로 바뀌지 않습니다.

## 실행

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run dev      # http://localhost:5173
npm run test     # vitest
npm run build    # dist/ 에 배포용 파일 생성
npm run preview  # 빌드 결과를 배포와 같은 방식으로 미리 보기
```

웹 앱을 Capacitor로 감싼 iPhone 앱에 감자 위젯을 붙였습니다. 앱을 안 열수록 위젯 속 감자가 화를 냅니다.
설치·시연 방법은 [docs/ios-widget.md](docs/ios-widget.md)를 보세요. 웹(Vercel) 배포에는 영향이 없습니다.

## 배포 (GitHub → Vercel)

배포 설정은 `vercel.json`에 들어 있어서 Vercel 화면에서 따로 바꿀 값이 없습니다.
(Vite 프레임워크, `npm ci` 설치, `npm run build` 빌드, `dist` 폴더 배포, 해시 붙은 파일은 1년 캐시)

### 처음 한 번

1. GitHub에서 새 저장소를 만듭니다. README·.gitignore·라이선스는 **추가하지 않은 빈 저장소**로 만드세요.
2. 이 폴더에서 저장소를 연결하고 올립니다. `<주소>`는 GitHub가 보여주는 저장소 주소로 바꿉니다.
   ```sh
   git remote add origin <주소>
   git push -u origin main
   ```
3. vercel.com에 GitHub 계정으로 로그인 → **Add New… → Project** → 방금 만든 저장소 **Import** → **Deploy**.
4. 1~2분 뒤 `https://<프로젝트이름>.vercel.app` 주소가 나옵니다.

### 그다음부터

`main` 브랜치에 push하면 Vercel이 자동으로 다시 배포합니다. 다른 브랜치에 push하면 미리보기 주소가 따로 생깁니다.

### 배포 후 확인할 것

- 폰에서 주소를 열고 "홈 화면에 추가" → 감자 아이콘과 "감자 키우기" 이름으로 설치되는지
- 시연 도구에서 미접속 일수를 7일로 → 브라우저 탭 아이콘이 화난 감자로 바뀌는지
- 진행 상황은 각 기기의 브라우저에만 저장됩니다. 다른 폰에서 열면 처음부터 시작합니다.
