## 프롬프트

대학생 커리어 앱 **「감자 키우기」**의 **발표용 소개 영상**을 만들어 줘.

### 기본 조건
- **화면:** 16:9 가로, 1920×1080, 약 40초
- **소리:** 내레이션 없음. 자막(화면 글자)으로만 설명. 배경음악은 넣어도 되고 빼도 돼.
- **분위기:** 귀엽고 따뜻하게. 광고처럼 과장하지 말고, 앱을 처음 보는 사람에게 소개하는 영상.
- **배경:** 크림색·크라프트지 같은 **종이 질감** 위에서 모든 게 움직여.
  - 캐릭터, 카드, 말풍선은 **흰 테두리를 두른 오려 붙인 스티커**처럼 보이게.
  - 폰 화면은 **마스킹테이프로 종이에 붙인 사진**처럼.
  - 움직임은 살짝 끊기는 **스톱모션 느낌**: 통 튀어나오고, 톡톡 떨어지고, 살랑 흔들림.
- **글씨:** 둥글고 귀여운 한글 손글씨풍(예: Jua체), 진한 갈색(#3a2a20).
- **자막:** 화면 아래 가운데 흰 종이 띠 위에 표시.

### 캐릭터 (가장 중요)
- 첨부한 `ref-mascot-happy.png`의 **감자 캐릭터를 그대로** 써 줘. 모양, 색, 눈, 볼터치를 바꾸지 마.
  - 동글동글한 갈색 감자에 까만 눈, 분홍 볼, 작은 점이 있고, 머리 위에 짧은 털 두 가닥이 있어.
- **감자는 말할 때 말풍선을 쓰고, 반말로 귀엽게 말해.**
- 머리 위 새싹이 단계별로 자라.
  - 싹이 없음 → 새싹 → 잎 두 장 → 꽃봉오리 → 감자꽃
- 유형별 소품은 `ref-mascot-outfits.png` 기준이야. 왼쪽부터:

| 유형 | 소품 |
|---|---|
| 차분 | 동그란 안경 |
| 활발 | 노란 머리띠 |
| 탐구 | 탐험 모자 |
| 창의 | 빨간 베레모 |
| 든든 | 네모 안경 + 힘준 눈썹 |

- 유형 테스트의 "유형 감자" 그림 다섯 장은 `ref-type-*.png`야. 팀원이 그린 그림이니 그대로 써 줘.

### 장면 구성 (scene-01 ~ 09 그림이 각 장면의 완성 모습)

1. **오프닝 (0~4초)** · `scene-01-open`
   - 연두색 종이 얼룩 위로 감자가 아래에서 쏙 올라와.
   - 말풍선이 "춘천엔 할 게 없다고?"에서 "있어! 나랑 같이 찾자."로 바뀌고, 감자가 통통 뛰어.
2. **타이틀 (4~8초)** · `scene-02-title`
   - 하늘색 종이 위에 "감자 키우기" 글자가 한 자씩 도장처럼 찍혀.
   - 옆에 새싹 난 감자가 있고, 아래에 "춘천 대학생이 감자랑 같이 크는 앱"이 나와.
3. **로드맵 (8~14초)** · `scene-03-roadmap`, `app-roadmap`
   - 왼쪽에 앱 로드맵 화면이 붙어.
   - 오른쪽에 "학년마다 할 일, 하나씩" 제목과 함께 1학년 탐색 / 2학년 첫 경험 / 3학년 실무 / 4학년 정리·지원 카드가 나와.
   - 카드에 하나씩 초록 체크가 찍힐 때마다 옆 감자의 싹이 한 단계씩 자라서, 마지막엔 꽃이 펴.
   - 자막: "로드맵 할 일에 기록을 남길 때마다 감자 싹이 자라요"
4. **춘천 기회 (14~20초)** · `scene-04-opps`, `app-opps`
   - "춘천 기회, 한곳에" 제목이 나오고, 기회 카드 네 장이 왼쪽에서 촤라락 날아와 붙어.
     - 공모전 · 춘천여행 SNS 공모전
     - 서포터즈 · 춘천인재육성장학재단 서포터즈
     - 인턴 · 미래내일 일경험 사업
     - 현장실습 · 강원대 동계 현장실습학기제
   - 오른쪽에는 앱 기회 화면이 있어.
   - 자막: "춘천·강원의 공모전, 서포터즈, 인턴을 내 학년에 맞춰 골라 줘요"
5. **돌보기 (20~26초)** · `scene-05-care`, `app-home`
   - 감자 머리 위로 물방울, 해, 새싹 아이콘이 차례로 떨어져. 그때마다 감자가 통 튀고 말풍선이 바뀌어.
     - 물방울: "꿀꺽꿀꺽, 시원해!"
     - 해: "따뜻해~ 광합성 중"
     - 새싹: "영양 만점! 쑥쑥 클게"
   - 뒤 종이 얼룩 색이 파랑 → 노랑 → 연두로 바뀌고, 아래 "기운" 막대가 차올라.
   - 자막: "물·햇빛·거름으로 감자를 돌봐요. 거름은 내 기록에서 생겨요"
6. **감자 유형 테스트 (26~31초)** · `scene-06-quiz`, `scene-07-quiz-outfits`, `app-quiz`
   - "나는 어떤 감자일까?" 아래로 유형 감자 다섯이 하나씩 통통 튀어나와 폴짝거려.
   - 이름표가 붙어: 차분한 / 활발한 / 탐구하는 / 창의적인 / 든든한 감자.
   - 이어서 다섯 마리가 차례로 **우리 감자 캐릭터 + 각 소품**으로 뿅 바뀌고, 이름표에 소품 이름이 나와.
   - 자막 1: "8문항 테스트로 내 감자 유형을 찾아요"
   - 자막 2: "결과에 맞춰 내 감자가 소품을 받고, 말투도 바뀌어요"
7. **지원 독려 (31~36초)** · `scene-08-apply`, `app-apply`
   - "보고 끝내지 말고, 지원까지" 제목 아래 큰 종이 버튼 "✓ 지원했어요"가 꾹 눌려.
   - 빨간 도장 "지원 완료!"가 쾅 찍히고 "거름 +1"이 새싹 아이콘과 함께 떠올라.
   - 감자가 신나서 뛰며 "지원했구나! 결과 나오면 알려 줘."라고 말해.
   - 자막: "지원하면 거름 1개. 스크랩만 해 둔 기회는 마감 전에 감자가 졸라요"
8. **엔딩 (36~40초)** · `scene-09-end`
   - 분홍 종이 얼룩 위에 감자꽃이 핀 감자가 살랑살랑 흔들려.
   - 색종이 조각이 내려오고 다음 글자가 차례로 나와.
     - 큰 글자 "감자 키우기"
     - "춘천에서, 감자랑 같이 한 뼘씩."
     - 주소 "gamki-home.vercel.app"

### 꼭 지킬 것
- 감자 캐릭터 디자인과 앱 화면(`app-*.jpg`)은 **새로 그리거나 바꾸지 말고** 첨부한 그대로 써.
- 한글 자막과 말풍선 문구는 위에 적은 그대로, **맞춤법 틀리지 않게**.
- 실제 사람, 실제 학교 로고, 다른 브랜드는 넣지 마.
- 배경은 끝까지 종이 질감 하나로 통일해. 장면 전환은 종이가 넘어가거나 스티커가 떼어지는 느낌으로.
